# Capturas de Pantalla de Pruebas

En esta carpeta debes almacenar las capturas requeridas por el enunciado:

1. **`01_registro_consola.png`**: Captura del cliente de consola o cURL realizando un registro exitoso (`POST /registro`).
2. **`02_contrasena_hasheada_sqlite.png`**: Captura de la base de datos `tareas.db` (vía SQLite CLI, DB Browser for SQLite o script) mostrando la columna `contrasena` con su hash criptográfico.
3. **`03_login_exitoso.png`**: Captura del inicio de sesión exitoso (`POST /login`).
4. **`04_login_fallido.png`**: Captura del intento de inicio de sesión con contraseña incorrecta (código 401).
5. **`05_endpoint_tareas_html.png`**: Captura del navegador web accediendo a `http://127.0.0.1:5000/tareas` visualizando la pantalla de bienvenida.
6. **`06_tests_automatizados.png`**: Captura de la consola ejecutando `python test_api.py` con todos los tests pasando exitosamente.
